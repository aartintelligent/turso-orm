# Security policy

## Supported versions

Only the latest published minor version of each crate receives security fixes.

## Reporting a vulnerability

Please do **not** open a public issue for security problems.

Use GitHub's private vulnerability reporting on this repository
(*Security* tab → *Report a vulnerability*). You will get an acknowledgement
within 72 hours and a fix or mitigation plan within 14 days for confirmed
issues.

Vulnerabilities in the Turso engine itself should be reported to
<https://github.com/tursodatabase/turso/security>.
